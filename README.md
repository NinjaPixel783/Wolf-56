# Wolf-56
Programme-multi agent servant à controler un apareil a distance après avoir lancé le programme dessus.

# Lancement du server :
1. Dezipez le dossier compressé
2. Ouvrez le dossier decomprésé
3. Dans la barre du haut tapez "cmd" puis attendez que le terminal s'ouvre
4. Dans le cmd écrivez "py server.py" pour lancer le serveur attendez de voir un lien http et ouvrez-le
5. Vous avez maintenant accés au dashboard.

# Lancement sur apareil cible :
1. Sur l'appareil que vous souhaitez contrôler, ouvrez le dossier de Wolf-56
2. Dans la barre du haut écrivez "cmd" et attendez que la fenêtre s'ouvre
3. Dans le cmd écrivez "py consent.py" et attendez de foir un ID
4. Vous pouvez retourner au dashboard et voir votre appareil
